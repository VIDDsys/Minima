# Summarize document

1. If a path is given, use `read_sandbox_file` or `read_file` (when workspace granted).
2. Produce: **TL;DR** (1–2 sentences), **Key points** (bullets), **Open questions**.
3. Keep the summary under 200 words unless asked for more.
4. Do not invent facts not present in the source.
