# Daily notes

1. Prefer writing to `notes/YYYY-MM-DD.md` via `write_sandbox_file` or `write_file`.
2. Structure: date heading, bullets for Done / Doing / Blockers.
3. Append rather than overwrite when the file already exists (read first).
4. Confirm the path written in one short sentence.
